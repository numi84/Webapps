# 🎮 Web Apps Hub

Eine Sammlung von interaktiven Web-Anwendungen, entwickelt mit Vanilla JavaScript, HTML und CSS.

## 📱 Enthaltene Apps

### Spiele
1. **💣 Minesweeper** - Klassisches Minesweeper mit 3 Schwierigkeitsgraden
2. **🎲 Yatzy** - Würfelspiel mit vollständiger Punkteberechnung
3. **🧩 Schiebepuzzle** - 3x3, 4x4 oder 5x5 Puzzle
4. **🃏 Memory** - Kartenspiel mit verschiedenen Schwierigkeitsstufen
5. **🐍 Snake** - Klassisches Snake-Spiel mit Highscore
6. **🎮 Tetris** - Vollständiges Tetris mit Level-System

### Produktivität
7. **📝 Todo Liste** - Aufgabenverwaltung mit LocalStorage
8. **⏱️ Pomodoro Timer** - Zeitmanagement mit Statistiken

### Tools
9. **🎨 Zeichnen-App** - Canvas-basierte Zeichen-Anwendung
10. **🧮 Taschenrechner** - Einfacher Taschenrechner

## 🚀 Features

- ✅ Komplett in Vanilla JavaScript (kein Framework benötigt)
- ✅ Responsives Design für Mobile und Desktop
- ✅ LocalStorage für Datenpersistenz (wo sinnvoll)
- ✅ Moderne, ansprechende UI mit Farbverläufen
- ✅ Tastatur- und Touch-Unterstützung
- ✅ Keine externen Abhängigkeiten

## 📂 Projektstruktur

```
Webapps/
├── index.html              # Hub-Seite mit Links zu allen Apps
├── styles/

├── apps/
│   ├── minesweeper/
│   ├── yatzy/
│   ├── sliding-puzzle/

│   ├── drawing/

│   ├── snake/

```

## 🎯 Verwendung

1. Öffne `index.html` in einem modernen Webbrowser
2. Wähle eine App aus der Übersicht
3. Viel Spaß!

## 🛠️ Technologien

- HTML5
- CSS3 (mit Flexbox & Grid)
- Vanilla JavaScript (ES6+)
- Canvas API (für Spiele und Zeichen-App)
- LocalStorage API (für Datenpersistenz)
- Web Audio API (für Sounds)
- Notifications API (für Benachrichtigungen)

## 📱 Browser-Kompatibilität

- Firefox

- Opera

- Einheitliches Farbschema

## 🔧 Erweiterung

Neue Apps können einfach hinzugefügt werden:
1. Erstelle einen neuen Ordner in `apps/`
2. Füge HTML, CSS und JS Dateien hinzu
3. Aktualisiere `index.html` mit einem neuen App-Card
